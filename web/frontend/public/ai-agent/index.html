安装桌面应用，选择 CodexInstall the desktop app and choose Codex

  1. 用电脑打开 chatgpt.com/download，下载 ChatGPT 桌面应用。On your computer, open chatgpt.com/download and download the ChatGPT desktop app.
  2. 安装、登录你自己的 ChatGPT 账号，然后在左上角选择 Codex。可用性依你的账号和工作区设置而定。Install it, sign in to your own ChatGPT account, then choose Codex from the top-left menu. Availability depends on your account and workspace.
  3. 新建一个 Codex 聊天，发送「请回复一句你已准备好帮我做课前设置」。Start a Codex chat and send: “Reply with one sentence saying you are ready to help me with pre-class setup.”
成功信号：Codex 回复了你。Success signal: Codex replies.

把这条命令给 Codex，让它在终端里运行。仓库只包含脱敏的三个 Skill 和虚构/获授权素材，不含公司正式表格。Give this command to Codex and let it run in the terminal. The repository contains only the three sanitised Skills and fictional or authorised assets, with no company formal forms.

跑一次安全的首次检查Run one safe first-use check

这个检查只用包内虚构资料，不需要你的客户文件、声音、照片、登录或 API key。This check uses only bundled fictional data. It does not need client files, your voice, portrait, login, or API key.

Run the first-use checks for propnex-forms, agent-shot, and pg-cobroke. Use Training mode and only bundled fictional data. Do not log in, send, upload identity media, call a paid API, or use a cloned voice.
Training mode only

如果 agent-shot 说缺少本地视频依赖，这不影响上课：课上可以先用包内 Golden Sample，再在课后完成本机渲染。If agent-shot reports a missing local video dependency, class can still proceed with the bundled Golden Sample; finish local rendering after class.

成功信号：三个 Skill 都回报 Training mode 边界，没有请求真实资料。Success signal: all three Skills report Training-mode boundaries and request no real data.
